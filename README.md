# Tribute Page Project – Oasis Infobyte Internship

## 1. HTML Structure
My project contains one main HTML file called index.html. 
This file has the complete structure of the webpage.

### Sections:
- **Heading**: <h1> tag – Tribute to Dr. APJ Abdul Kalam
- **Image**: <img> tag – shows his photo
- **Introduction Paragraph**: <p> – who he is, why inspiring
- **Why I Admire Him**: <h2> + <ul><li> – bullet points
- **Quote Section**: <p class="quote"> – inspirational quote

## 2. CSS Structure
- **style.css** file – styling for colors, fonts, layout
- Body styling: dark background, white text
- Container: centered, box-shadow, rounded corners
- Headings: colored text
- Image: centered, rounded corners
- Quote: italic, centered, light blue
